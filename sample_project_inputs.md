# Sample Project Inputs — `/projects/new`

Use these 20 ready-to-paste inputs on the **Create New Project** page.

## How to use this file

1. Choose a row.
2. Select **Content Type** = the value in the `content_type` column.
3. Fill each form field with the matching value below.
4. Click **Create Project** and start the workflow from the project page.

### Cost-friendly style tips

- **Stock Footage** / **Explainer** / **Whiteboard** use the most free stock assets (`$0.00`) and cheapest AI images.
- **Cinematic** / **Documentary** may fall back to more `ai_image`/`ai_video` calls, increasing cost.
- Keep `target_duration_seconds` short (60–90 sec) for quick, cheap smoke tests.
- Use 180–300 sec for a more polished, final-quality result.

## Field reference

| Field | Notes |
|---|---|
| `title` | 1–300 chars, required. |
| `description` | 0–5000 chars. More detail = better scripts. |
| `language` | `en`, `es`, `fr`, `de`, `hi`, `zh`, `ja`. |
| `audience` | e.g. "beginners, tech enthusiasts". |
| `content_type` | Choose `youtube_video` for full video pipeline. |
| `video_style` | See cost tips above. |
| `target_duration_seconds` | 1–86400. Recommend 60–300 for testing. |
| `tags` | Comma-separated (frontend turns it into a list). Max 20. |
